# Sleepify

Sleepify helps you figure out when to go to bed or when to wake up.

Start with your wake-up time to find a good bedtime, or enter your bedtime to see when you could wake up. Sleepify uses 90-minute sleep cycles and takes into account how long you need to fall asleep.

You can adjust the number of sleep cycles and allow up to 45 minutes to drift off. Suggested times are shown in a 24-hour format, along with how much sleep you'll get—even if your night stretches into the next day.

Found a wake-up time that works for you? Set an alarm right from the app.
